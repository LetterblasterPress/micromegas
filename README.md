Welcome to the Micromégas Project page. This site documents the planning and
design of the [Letterblaster Press](https://github.com/LetterblasterPress)
edition of *Micromégas* by Voltaire.

|                    |                                          |
|--------------------|------------------------------------------|
| **Title**          | Micromegas                               |
| **Author**         | Voltaire                                 |
| **Translator**     | Peter Phalen                             |
| **URL**            | <https://www.gutenberg.org/ebooks/30123> |
| **Translation of** | <https://www.gutenberg.org/ebooks/4649>  |

[Letterblaster Press](https://github.com/LetterblasterPress) aims to provide
ready-to-print PDFs of public domain texts that are thoughtfully designed with a
keen eye for typographic details. Letterblaster PDFs are designed for print with
the hand bookbinder in mind. If you're looking to read this work online or on an
e-reader, check out the Project Gutenberg links above for more suitable file
formats.

This design was created as a digital proof for a book to be typeset and printed
by hand. The typeface is [*Centaur &
Arrighi*](https://en.wikipedia.org/wiki/Centaur_(typeface)), as released by
Monotype in 1929 and digitized in 1990, and the letterpress edition is set using
the "11 on 12" catalog offering from [M&H
Type](https://www.arionpress.com/mandh-about) which casts 11-point[^readme-1]
glyphs on a 12-point body.

[^readme-1]: Digital designs typically use a standard of 72 points per inch, but
    this design uses the somewhat smaller (American) Monotype standard of 72.27
    per inch.
