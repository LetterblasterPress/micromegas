# Micromégas Project

Welcome to the Micromégas Project page. This site documents the planning
and design of the [Letterblaster
Press](https://github.com/LetterblasterPress) edition of *Micromégas* by
Voltaire.

|                    |                                          |
|--------------------|------------------------------------------|
| **Title**          | Micromegas                               |
| **Author**         | Voltaire                                 |
| **Translator**     | Peter Phalen                             |
| **URL**            | <https://www.gutenberg.org/ebooks/30123> |
| **Translation of** | <https://www.gutenberg.org/ebooks/4649>  |

[Letterblaster Press](https://github.com/LetterblasterPress) aims to
provide ready-to-print PDFs of public domain texts that are thoughtfully
designed with a keen eye for typographic details. Letterblaster PDFs are
designed for print with the hand bookbinder in mind. If you’re looking
to read this work online or on an e-reader, check out the Project
Gutenberg links above for more suitable file formats.
